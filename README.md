# Australia Tech Map

A map-first opportunity-intelligence platform for Australian technology employment — discover employers, track hiring and evidence-backed sponsorship information, and monitor regional opportunity, all traceable to a source.

## Status

Implementation is underway. Phases 0, 1, 2, and 3 are closed. Phase 1's web/worker/CI foundation, database schema, fenced ingestion job lifecycle, and observability are merged; the sample importer persists a reviewed, audited snapshot; staging promotion and the Vercel web deployment have both run successfully against real infrastructure. Phase 2's geographic foundation closed on 5 September 2026 against real, verified data: real ABS ASGS boundaries (6,072 regions across SA4/SA3/SA2/LGA/POA) and Home Affairs postcode rules (5,239 rows) are imported and activated in Neon; all 125 real Phase 3 locations carry a real regional/migration-category classification; and the G-NAF exact-match address pipeline, run against the real August 2026 release (17M indexed addresses) and compared against the 133-company cohort, resolves 93/133 (69.9%) to a unique, confident match with a median 27m offset from their existing geocoded coordinates (see IMPLEMENTATION_PLAN.md's Phase 2 exit gate for the full accuracy breakdown). Phase 3's employer-identity pipeline is seeded with real data end to end: 133 real, researched employers exist in the real Neon database with 0% unresolved duplicates, 100% usable locations, and 100% provenance — all verified by direct query, not just by the pipeline's own report (see IMPLEMENTATION_PLAN.md's Phase 3 exit gate for the exact numbers and queries). Locations were originally resolved via a third-party geocoding API — OpenStreetMap's Nominatim by default, Mapbox as an opt-in alternative — as a deliberate interim stand-in for Phase 2's G-NAF pipeline (see ARCHITECTURE_DECISIONS.md §4.3); now that G-NAF is real and activated, its documented upgrade trigger has been applied using reviewed, tested functions (not ad hoc SQL): 93 of the 133 companies now carry a real `gnaf_exact_match` location, each with its prior geocoder state preserved as an audit record; the remaining 40 (ambiguous or no-match against G-NAF) correctly keep their interim Nominatim/Mapbox location rather than a guessed one. Category enrichment ran against the real database on 5 September 2026: a keyword classifier mapped each company's seed-research description to Appendix A.1's niche taxonomy, giving 53/133 companies (39.8%) at least one assigned niche across 58 links, verified by direct query; the map/search UI's category filter now reflects this real data. Per-record manual verification remains open as ordinary follow-up work. Phase 4's map/search/employer-profile alpha slice is live against real data: a MapLibre GL JS map (ARCHITECTURE_DECISIONS.md §3.5, switched from Mapbox GL JS to avoid its forced-payment-method signup) showing all 133 real company pins, a `pg_trgm`-backed company/alias search verified correct on an exact match and a real typo, and real employer profile pages — all verified end to end against the live production database, not just against tests. Regional-status filtering and structured postcode/region search now have real Phase 2 data behind them but still need their own UI wiring, not yet built; role/hiring filters and the full golden-query relevance suite remain correctly deferred to Phase 5/6B; full analytics wiring awaits a PostHog account decision; load-testing awaits a realistic 1,000-employer fixture. Phase 5's hiring-intelligence alpha slice has real jobs flowing from 9 real companies (up from 2): besides Immutable (Lever) and Dovetail (Ashby), independently fetching and verifying each of the 133 seeded companies' real careers pages against known ATS APIs found Kasada, Zeller, Megaport, Easy Agile, and Lumary on Lever, plus Morse Micro, Vow, and Up (Ferocia) on Ashby — 92 real job postings are now persisted, classified (role family/seniority/work style), and skill-linked in the real database, up from 11, across all 10 registered sources (Easy Agile legitimately has 0 open roles right now). A third ATS adapter (Greenhouse) is now built and tested, registering Culture Amp and Catapult Sports — not yet run against production. BambooHR/Workday/SmartRecruiters/Workable hits from the same research still have no adapter — a scope decision pending priority, not an oversight. SSRF-safe fetch controls (`fetch_safety.py`) gate every outbound crawler request, tested against 12 real-world attack vectors including DNS-rebinding and cloud-metadata addresses. The static-HTML/Playwright crawler tiers, 300-source onboarding, and hiring-momentum derivation all remain open, named rather than faked. Phase 6 Track 6A (sponsorship evidence) has real, tested infrastructure that has now run against production with real results, verified by direct query: a conservative keyword classifier deriving current/historical explicit evidence from Phase 5's real job postings found zero hits (confirmed honest, given only 9 companies/92 jobs exist), and a Home Affairs labour-agreement matcher was run against a real 6,113-record acquisition (the public list's backend API, found via a real browser, rather than the blocked direct-fetch page) — 4 of the 133 real companies exact-matched (5 evidence rows, since Canva independently holds two separate agreements), 1 routed to `/admin/review` as a `pg_trgm` fuzzy match needing a human judgement call (Mineral Resources Tech vs. Mineral Resources Limited, similarity 0.55), and 128 had no match. The employer profile UI and the map/search sponsorship filter now reflect this real, non-zero coverage (4/133 companies, 3.0%). Track 6B (JSA NERO/IVI, the Regional Tech Opportunity Score) is out of scope for the alpha per its own "ship 0-6A, not 0-6B" checkpoint and hasn't been started. See IMPLEMENTATION_PLAN.md's Phase 2, 4, 5, and 6 exit gates for specifics, and ARCHITECTURE_DECISIONS.md §3.4 and §4.1 for other known, deliberate interim deviations (Vercel Hobby tier, and unauthenticated admin pages) that must close before any real user or commercial activity.

## Delivery approach

Ship a private alpha first — 100–200 curated employers across Sydney, Melbourne, Brisbane, and selected regional centres, three ATS integrations, map/search/profiles, and sponsorship evidence — before building Opportunity Match, alerts, or scaling to the full 1,000-employer V1 target. See IMPLEMENTATION_PLAN.md §5 for the milestone breakdown.
