# Australia Tech Map

A map-first opportunity-intelligence platform for Australian technology employment — discover employers, track hiring and evidence-backed sponsorship information, and monitor regional opportunity, all traceable to a source.

## Status

Implementation is underway. Phases 0, 1, and 3 are closed. Phase 1's web/worker/CI foundation, database schema, fenced ingestion job lifecycle, and observability are merged; the sample importer persists a reviewed, audited snapshot; staging promotion and the Vercel web deployment have both run successfully against real infrastructure. Phase 3's employer-identity pipeline is seeded with real data end to end: 133 real, researched employers exist in the real Neon database with 0% unresolved duplicates, 100% usable locations, and 100% provenance — all verified by direct query, not just by the pipeline's own report (see IMPLEMENTATION_PLAN.md's Phase 3 exit gate for the exact numbers and queries). Locations were resolved via a third-party geocoding API — OpenStreetMap's Nominatim by default, Mapbox as an opt-in alternative — as a deliberate interim stand-in for Phase 2's not-yet-loaded G-NAF pipeline (see ARCHITECTURE_DECISIONS.md §4.3). Category enrichment ran against the real database on 5 September 2026: a keyword classifier mapped each company's seed-research description to Appendix A.1's niche taxonomy, giving 53/133 companies (39.8%) at least one assigned niche across 58 links, verified by direct query; the map/search UI's category filter now reflects this real data. Per-record manual verification remains open as ordinary follow-up work. Phase 4's map/search/employer-profile alpha slice is live against real data: a MapLibre GL JS map (ARCHITECTURE_DECISIONS.md §3.5, switched from Mapbox GL JS to avoid its forced-payment-method signup) showing all 133 real company pins, a `pg_trgm`-backed company/alias search verified correct on an exact match and a real typo, and real employer profile pages — all verified end to end against the live production database, not just against tests. Regional-status filtering and structured postcode/region search remain blocked on Phase 2's not-yet-imported geography data; role/hiring/sponsorship filters and the full golden-query relevance suite remain correctly deferred to Phases 5–6; full analytics wiring awaits a PostHog account decision; load-testing awaits a realistic 1,000-employer fixture. Phase 2's geographic-foundation schema, ASGS/G-NAF/Home Affairs importers, and point-in-polygon resolution are built and tested, but its exit gate stays open until real ABS/G-NAF data is actually imported. Phase 5's hiring-intelligence alpha slice has real jobs flowing end to end: two of the 133 real seeded companies (Immutable, Dovetail) were found — by actually fetching their careers pages, not by URL pattern alone — to use Lever and Ashby respectively; both adapters are verified against real live API responses, and 11 real job postings are persisted, classified (role family/seniority/work style), and skill-linked in the real database. SSRF-safe fetch controls (`fetch_safety.py`) gate every outbound crawler request, tested against 12 real-world attack vectors including DNS-rebinding and cloud-metadata addresses. Greenhouse/Workable/BambooHR/SmartRecruiters adapters, the static-HTML/Playwright crawler tiers, 300-source onboarding, and hiring-momentum derivation all remain open, named rather than faked. See IMPLEMENTATION_PLAN.md's Phase 2, 4, and 5 exit gates for specifics, and ARCHITECTURE_DECISIONS.md §3.4 and §4.1 for other known, deliberate interim deviations (Vercel Hobby tier, and unauthenticated admin pages) that must close before any real user or commercial activity.

## Delivery approach

Ship a private alpha first — 100–200 curated employers across Sydney, Melbourne, Brisbane, and selected regional centres, three ATS integrations, map/search/profiles, and sponsorship evidence — before building Opportunity Match, alerts, or scaling to the full 1,000-employer V1 target. See IMPLEMENTATION_PLAN.md §5 for the milestone breakdown.
